## ADDED Requirements

### Requirement: Авторизация через встроенный webview
При отсутствии валидной сессии приложение открывает webview c auth-потоком Zvuk
(id.zvuk.com / Sber ID). WAF Servicepipe проходит нативно внутри webview (JS-челлендж).

#### Scenario: Первый вход
- **WHEN** пользователь открывает приложение без сохранённого токена
- **THEN** показывается окно авторизации; после успешного входа токен извлекается и webview закрывается

### Requirement: Хранение токена
Токен хранится в macOS Keychain (не в открытом виде). При старте приложение читает токен
из Keychain и использует заголовок `X-Auth-Token`.

#### Scenario: Перезапуск приложения
- **WHEN** приложение перезапускается после успешного входа
- **THEN** сессия восстанавливается из Keychain без повторного ввода пароля

### Requirement: Refresh-цикл токена
При 401 от API приложение обновляет токен через `/web-api/v2/token/refresh` и повторяет запрос.

#### Scenario: Истёкший токен
- **WHEN** API возвращает 401
- **THEN** выполняется refresh и исходный запрос повторяется прозрачно для пользователя
