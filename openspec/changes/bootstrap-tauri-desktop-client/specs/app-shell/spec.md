## ADDED Requirements

### Requirement: Tauri 2 каркас приложения
Система собирается как macOS-приложение на Tauri 2 с Rust-backend (`src-tauri/`)
и webview-frontend. Сборка: `cargo tauri build` (или pnpm-скрипт), запуск dev: `cargo tauri dev`.

#### Scenario: Первая сборка
- **WHEN** выполняется сборка проекта из чистого клона
- **THEN** собирается .app, который запускается на macOS и открывает главное окно

### Requirement: Навигация и layout
Приложение имеет постоянный layout: сайдбар разделов (Главная, Поиск, Коллекция,
Плейлисты, Подкасты), нижний плеер-бар, контентную область.

#### Scenario: Переключение разделов
- **WHEN** пользователь выбирает раздел в сайдбаре
- **THEN** контентная область переключается без перезагрузки окна, состояние плеера сохраняется
