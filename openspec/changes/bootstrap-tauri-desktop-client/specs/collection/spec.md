## ADDED Requirements

### Requirement: Коллекция пользователя
Экран «Коллекция»: лайкнутые треки, релизы, артисты, плейлисты
(`getPaginatedCollection`, `getCollectionIds`, `getCollectionCount`).

#### Scenario: Просмотр лайкнутых треков
- **WHEN** пользователь открывает раздел «Коллекция»
- **THEN** видит свои лайкнутые треки с возможностью запуска и постановки в очередь

### Requirement: Лайки/дизлайки
Лайк/снятие лайка через `addItemToCollection` / `removeItemFromCollection` с оптимистичным UI.

#### Scenario: Лайк трека
- **WHEN** пользователь жмёт «сердечко» у трека
- **THEN** трек добавляется в коллекцию без перезагрузки; при снятии лайка — удаляется
