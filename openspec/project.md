# Project: zvuk-desktop

## Контекст
Неофициальный десктоп-клиент музыкального сервиса Zvuk (Сбер Звук, https://zvuk.com) для macOS.
Язык: Rust. Платформа: Tauri 2 (решение зафиксировано владельцем проекта — приложение на Rust).
Владелец: Леха (senior .NET/TS). Ответы — на русском.

## Область функционала
Весь персональный функционал Zvuk: поиск, лента/подборки, релизы/треки, плейлисты,
избранное, подкасты, плеер (play/pause/seek/queue/shuffle/repeat), media keys, Now Playing.
Исключение допустимо только для раздела «Атлас».

## Авторизация
Повторная авторизация через собственную сессию пользователя; токены — как в веб-версии
(X-Auth-Token + /web-api/v2/token/refresh, auth-хост id.zvuk.com). Хранение — macOS Keychain.

## Conventions
- Spec-driven development: изменения через openspec/changes, спеки в openspec/specs.
- Исследовательские находки — в docs/research (артефакты веб-бандла — tools/artifacts).
- Сторонние скиллы — в skills/ с обязательным сканом SkillSpector (см. skills/SOURCES.md).
- Поиск по коду: Graphify (индекс) -> CodeGraph (навигация) -> tgrep (паттерны).

## Границы
- Никакого обхода DRM; работаем только с тем, что доступно аккаунту пользователя.
- Не копировать закрытый код веб-плеера — только контракты API и собственная реализация.
